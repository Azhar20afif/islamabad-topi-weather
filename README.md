# Personal Weather — Islamabad & Topi

A Chrome/Edge toolbar extension that shows current temperature and a short today/tomorrow highlight for **Islamabad** and **Topi**.

**Live demo:** https://azhar20afif.github.io/islamabad-topi-weather/

## Download the extension

1. Open this repository: https://github.com/Azhar20afif/islamabad-topi-weather
2. Click the green **Code** button
3. Click **Download ZIP**
4. Unzip the folder (you should see `manifest.json` inside)

Or with git:

```bash
git clone https://github.com/Azhar20afif/islamabad-topi-weather.git
```

## Load it in Chrome or Edge

This extension is not on the Chrome Web Store. Load it unpacked:

1. Open Chrome or Edge
2. Go to `chrome://extensions` (Chrome) or `edge://extensions` (Edge)
3. Turn on **Developer mode** (top right)
4. Click **Load unpacked**
5. Select the unzipped project folder (the one that contains `manifest.json`)
6. Pin the extension from the puzzle-piece toolbar menu
7. Click the **Personal Weather** icon

The popup shows current temperature, today’s and tomorrow’s high/low, and a short highlight such as “Sunny today · rain tomorrow”.

If you change files later, go back to the extensions page and click **Reload** on this extension.

## What you need

- Chrome or Microsoft Edge
- An internet connection (forecast comes from [Open-Meteo](https://open-meteo.com/))
